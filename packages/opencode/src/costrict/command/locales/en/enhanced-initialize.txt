- Core Traversal Priority: **Directories take precedence over files; breadth-first over depth-first**:

  ② Directory-First Display: Prioritize complete presentation of directory hierarchy, then use remaining lines to supplement core files within directories, without missing high-priority directories.
- Use "breadth-first" traversal, progressing from outer to inner directories layer by layer, selectively displaying based on priority;
- Skip common hidden directories/files: .vscode, .git, node_modules, vendor, dist, build, etc.;

- **Strictly use standard tree structure format**: Must use tree symbols like `├─`, `└─`, `│`; Markdown list symbols (`-`, `*`, etc.) are prohibited;

- Each directory/file comment must be ≤30 characters and **must include "core functionality + development positioning"**, avoiding generic descriptions (e.g., just "business logic"), providing index/navigation value to help AI quickly locate and understand purpose;
- Small projects display to file level; medium-to-large projects selectively display to "directory + core files" level based on priority.
- Final output contains only project directory structure and comment descriptions, no other irrelevant information or redundant content.

- Folding is only for: freeing up lines to include more high-priority items, or simplifying low-priority items when approaching line limits;
